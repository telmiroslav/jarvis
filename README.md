# Jarvis

Голосовой помощник на плате ESP32-S3. Ты говоришь «Jarvis», он просыпается, слушает, отвечает голосом, а на экране у него лицо.

- Слово «Jarvis» плата узнаёт **сама**, без интернета (с v0.5.0 по собственной модели «Джарвис», обученной Давидом).
- Дальше разговор идёт через ИИ: плата слушает и говорит, а думает ноутбук.
- Позже Jarvis научится делать дела: управлять компьютером, включать музыку, свет.

## Как это устроено

```
   Плата                          Ноутбук Давида                     ИИ
 уши, рот, лицо   <-- Wi-Fi -->   мозг (сервер)   <-- VPN -->   (в интернете)
 микрофон, динамик               слушает, решает,
 экран                           говорит, делает дела
```

- **Плата** это уши (микрофон), рот (динамик) и лицо (экран). Своих мыслей у неё нет.
- **Мозг** это программа-сервер на ноутбуке Давида. К ИИ она ходит через VPN, а плата к ноутбуку подключается по домашнему Wi-Fi.
- **Умения** (управление ПК на Hyprland, музыка, свет) подключаются к мозгу через вызов функций у ИИ: ИИ сам решает, какую функцию дёрнуть.

## Для Давида

Как поставить всё и прошить плату: **[docs/FLASHING.md](docs/FLASHING.md)**.
Какие провода куда: **[docs/WIRING.md](docs/WIRING.md)**.

Аккаунт GitHub не нужен. Один раз ставишь программы и делаешь `git clone https://github.com/telmiroslav/jarvis.git`, дальше каждый тест это одна команда:

```
cd jarvis && git pull && ./tools/flash.sh
```

Лог сохранится в `~/jarvis-logs`, его файл нужно прислать Мирославу.

Проект открытый, лицензия MIT.

## Чужие компоненты

Прошивка собирается из готовых библиотек. Слово «Джарвис» с v0.5.0 по умолчанию узнаёт **microWakeWord** (TensorFlow Lite Micro):
собственная модель `firmware/main/models/jarvis_ru.tflite`, которую Давид обучил фреймворком microWakeWord (OHF-Voice/micro-wake-word,
Apache-2.0; отчёт об обучении лежит рядом, `jarvis_ru.REPORT.md`). Запускают её три компонента с закреплёнными версиями
(`firmware/main/idf_component.yml`), все с лицензией Apache-2.0 (тексты лежат в самих компонентах, в файле `LICENSE`):

- `espressif/esp-tflite-micro` 1.4.1: порт TensorFlow Lite Micro для ESP-IDF от Espressif. Внутри чужие библиотеки: flatbuffers,
  gemmlowp и ruy (Apache-2.0), kissfft (BSD-3-Clause);
- `espressif/esp-nn` 1.4.2: быстрые 8-битные ядра свёрток для ESP32-S3 (Apache-2.0). Закреплена версия 1.4.2, а не 1.5.0, которую
  берёт ESPHome: 1.5.0 вышла 11.11.2026 и на момент выбора ей не было двух недель; 1.4.2 собирается с esp-tflite-micro 1.4.1;
- `esphome/esp-micro-speech-features` 1.2.3: микрофронтенд (признаки звука для модели), ответвление микрофронтенда TensorFlow Lite Micro,
  сделанное для microWakeWord (Apache-2.0, внутри kissfft под BSD-3-Clause).

Код ESPHome `micro_wake_word` (GPLv3) в репозиторий **не скопирован**: свой код движка написан заново (`firmware/main/mww*.cc`, MIT).

**Модель слова обучена на данных, часть которых разрешена только для некоммерческого использования** (список наборов и их происхождение
в `firmware/main/models/jarvis_ru.REPORT.md`: голоса Piper, русская речь Golos, фон, шумы и записи самого Давида). Поэтому модель,
как и голос OmniVoice на сервере, годится для личного использования; для коммерческого нужно переобучить её на разрешённых данных.
Записи голоса Давида, на которых модель проверялась, в репозиторий не входят (личные данные).

Прежний движок слова, **ESP-SR** (Espressif, версия 2.6.1), остался на плате: он по-прежнему отвечает за конец фразы (детектор речи
VADNet) и работает как запасной движок слова (нейросеть WakeNet9 `wn9_jarvis_tts`; включается командой `wake engine esp`, а плата сама
переходит на него, если microWakeWord не поднялся). Лицензия ESP-SR лежит в самом компоненте (файл `LICENSE`, «ESPRESSIF MIT License»):
это текст MIT, но разрешение выдано на использование «на всех продуктах ESPRESSIF SYSTEMS», то есть на чипах Espressif (наша плата
ESP32-S3 подходит). Библиотеки ESP-SR и файлы моделей идут готовыми бинарниками без исходников, и в образ прошивки входит модель слова.
На остальной код репозитория это не распространяется: он под MIT, как сказано выше. Espressif пишет, что большинство моделей слов
обучены на синтезированной речи и их качество в чужих условиях не гарантируется, поэтому чувствительность слова настраивается
командами (`docs/FLASHING.md`).

Остальное: ESP-IDF, esp_websocket_client, led_strip и esp_lvgl_port (Apache-2.0), LVGL, esp-dl и cJSON (MIT), шрифт Inter
(SIL OFL 1.1, текст в `firmware/main/fonts/OFL.txt`), `tools/nvs_partition_gen.py` (Apache-2.0, текст в
`tools/LICENSE.nvs_partition_gen.Apache-2.0`).

## Что где лежит

```
firmware/                  прошивка (ESP-IDF v5.5.6, ESP32-S3)
firmware/test_host/        проверки на обычном компьютере: тесты логики, движка слова (признаки и модель на синтетическом звуке) и картинки интерфейса (./run.sh, картинки в renders/)
firmware/main/models/      модель слова «Джарвис» (microWakeWord: .tflite, манифест .json) и отчёт об обучении
server/                    мозг на ноутбуке: распознавание речи, Gemini, голос OmniVoice (docs/SERVER.md)
tools/flash.sh             скачать готовую прошивку (публичный релиз), залить в плату, показать лог
tools/monitor.py           показ лога платы и запись его в файл
tools/wifi_set.py          передать плате имя Wi-Fi и пароль по серийному порту (его вызывает ./tools/flash.sh wifi)
docs/FLASHING.md           как прошить и что прислать обратно
docs/WIRING.md             подключение проводов
.github/workflows/         сборка прошивки на GitHub (firmware.yml)
```

## Для разработки (Мирослав)

- Каждый push в `main` собирает прошивку, готовый образ лежит в артефактах запуска (раздел Actions).
- Тег `v*` (например `git tag v0.0.2 && git push --tags`) публикует релиз с файлом `jarvis-firmware.bin`. Именно его скачивает `tools/flash.sh`.
- Образ целиком (загрузчик, таблица разделов, приложение и модель слова для ESP-SR) заливается по адресу `0x0`. Он весит около 9 МБ,
  почти всё это пустое место перед моделью (раздел `model` начинается с `0x820000`), поэтому `tools/flash.sh` пропускает только раздел
  настроек и заливает остальное.
- Версия прошивки (тег или `main-<коммит>`) пишется при сборке и видна в начале лога.
