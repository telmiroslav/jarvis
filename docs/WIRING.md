# Подключение проводов

Плата: ESP32-S3 N16R8. Номера в таблицах это GPIO (то, что написано на плате как `GPIO..` или просто числом).
Те же номера записаны в прошивке, файл `firmware/main/board.h`.

Сначала подключай **питание и землю**, потом остальное. Всё делай при отключённом USB.

## Экран ST7789 (1.54", 240x240)

| Вывод экрана | Куда на плате |
|---|---|
| SCL | GPIO 21 |
| SDA | GPIO 47 |
| RES | GPIO 45 |
| DC | GPIO 40 |
| CS | GPIO 41 |
| BLK | GPIO 42 |
| VCC | 3.3V |
| GND | GND |

## Микрофон INMP441

| Вывод микрофона | Куда на плате |
|---|---|
| SCK | GPIO 5 |
| WS | GPIO 4 |
| SD | GPIO 6 |
| L/R | GND (это левый канал) |
| VDD | 3.3V |
| GND | GND |

## Усилитель MAX98357A

| Вывод усилителя | Куда на плате |
|---|---|
| BCLK | GPIO 15 |
| LRC | GPIO 16 |
| DIN | GPIO 7 |
| VIN | 5V |
| GND | GND |

Динамик (4-8 Ом) подключается к выходам самого усилителя: **+** и **−**. К плате его напрямую не подключай.

## То, что уже есть на плате

| Что | GPIO |
|---|---|
| Цветной светодиод RGB | 48 |
| Кнопка BOOT | 0 |

## Проверь перед включением

- У экрана и микрофона питание **3.3V**, у усилителя **5V**. Не перепутай: микрофон от 5V может сгореть.
- Все GND соединены с GND платы.
- Эти выводы не используем: 35, 36, 37 (заняты памятью PSRAM) и 19, 20 (заняты USB).
