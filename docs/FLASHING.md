# Прошивка платы и отправка лога

Ничего собирать не нужно: прошивку собирает GitHub, а скрипт сам скачивает её и заливает в плату.

## Один раз: подготовка (Arch Linux)

Аккаунт GitHub не нужен: репозиторий открытый.

1. Поставь программы:

   ```
   sudo pacman -S git curl esptool python-pyserial
   ```

2. Скачай репозиторий:

   ```
   git clone https://github.com/telmiroslav/jarvis.git
   ```

3. Дай себе доступ к USB-портам и **выйди из системы и зайди снова** (или перезагрузись):

   ```
   sudo usermod -aG uucp $USER
   ```

   Проверка после входа: команда `groups` должна показать `uucp`.

## Каждый тест: одна команда

Подключи плату к ноутбуку и выполни:

```
cd jarvis && git pull && ./tools/flash.sh
```

Скрипт скачает последнюю прошивку, зальёт её, перезагрузит плату и покажет её лог.
Подожди, пока в логе появится строка `STEP0 RESULT:` (до 30 секунд), или сколько скажет Мирослав,
и нажми **Ctrl+C**.

Лог сам сохраняется в папку `~/jarvis-logs`. **Пришли Мирославу самый новый файл оттуда**
(скрипт в конце печатает его имя). Ещё коротко напиши, что видел на плате.

**Самый первый раз** (на плате раньше была другая прошивка) запусти с очисткой памяти:

```
./tools/flash.sh --erase
```

Другие команды:

| Команда | Что делает |
|---|---|
| `./tools/flash.sh` | последняя версия прошивки |
| `./tools/flash.sh v0.0.2` | конкретная версия |
| `./tools/flash.sh --erase` | сначала стереть всю память платы |
| `./tools/flash.sh monitor` | ничего не шить, только смотреть лог (плата перезагрузится) |
| `./tools/flash.sh file путь/к/файлу.bin` | прошить файл с диска |

## Какой USB-порт

У платы два разъёма USB-C: **COM** (UART) и **USB**. Подойдёт любой.
Если лог не появился (пусто), перетыкни кабель в другой разъём и запусти `./tools/flash.sh monitor`.

## Шаг 0: что должно быть

- [ ] Светодиод на плате по кругу меняет цвет: красный, зелёный, синий.
- [ ] Если нажать кнопку BOOT, светодиод становится белым.
- [ ] В логе есть строка, которая начинается с `STEP0 RESULT:`.

Напиши Мирославу, что из трёх пунктов получилось, и пришли файл лога.

## Если что-то не так

| Что видишь | Что делать |
|---|---|
| `Нет доступа к порту` | Группа uucp: пункт 3 подготовки, потом выйти и зайти |
| `Не получилось связаться с GitHub` | Проверь интернет и включи VPN, запусти ещё раз |
| `Готовой прошивки на GitHub пока нет` | Релиз ещё собирается: подожди пару минут или сообщение от Мирослава |
| `Релиз v... не найден` | Тег набран неверно. Версии есть на https://github.com/telmiroslav/jarvis/releases |
| `GitHub отказал (код 403 или 429)` | Подожди несколько минут и повтори |
| `Плата не найдена` | Другой кабель (нужен с данными) и другой разъём платы |
| Прошивка не заливается (`Failed to connect`) | Режим загрузки, см. ниже |
| В логе пусто | Нажми RST на плате или перетыкни в другой разъём |

### Режим загрузки руками

1. Зажми кнопку **BOOT** и держи.
2. Нажми и отпусти кнопку **RST**.
3. Отпусти **BOOT**.
4. Сразу запусти `./tools/flash.sh` ещё раз.

Не помогло: пришли Мирославу текст ошибки из терминала.

## Запасной вариант: прошить из браузера

Нужен Chrome или Chromium. Скрипт не нужен.

1. Скачай `jarvis-firmware.bin`: прямая ссылка на последнюю версию
   https://github.com/telmiroslav/jarvis/releases/latest/download/jarvis-firmware.bin
   (или со страницы https://github.com/telmiroslav/jarvis/releases, раздел Assets). Вход в GitHub не нужен.
2. Открой https://espressif.github.io/esptool-js/ и нажми Connect, выбери порт платы.
3. Flash Address: `0x0`. Выбери скачанный файл. Baudrate можно 460800.
4. Нажми Program. Когда закончится, нажми RST на плате.
5. Лог после этого смотри так: `./tools/flash.sh monitor`.
